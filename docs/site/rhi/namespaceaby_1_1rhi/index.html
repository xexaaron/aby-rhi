    Detailed Description

    A set of interfaces that can be set by the user to modify parts of the library.

    Parameters:

    • IInterface Do not use directly. it is the base class of interfaces.
    • ILogger Logging interface to pass pre-formatted messages to the application
    • IAllocator Allocator interface used in the backed and for other allocations.
